# Атлас AgPM — дизайн и фронтенд-прототип, v3

Прототип сайта «Атлас агентного управления проектами» для передачи в Claude Code как основы фронтенда. Дополняет задание на разработку «Задание на разработку: еженедельный Атлас агентного управления проектами, v2» (далее — задание); все правила атласа, модель данных и критерии приёмки — там.

Открывается без сервера: `index.html` из папки или сборка в одном файле `Атлас_прототип_v3.html`. Данные — октябрьский атлас (срез на 9 октября 2026, 794 материала), перенесённые в модель данных задания.

Атлас — отдельный продукт со своим знаком; единственная внешняя ссылка — на источник материалов AgPM Radar (radar.agpm.space). Логотипов и ссылок других продуктов на сайте нет.

## Что изменилось в v3

- Основной знак — «Меридиан» (`assets/logo/mark-meridian.svg`): глобус с меридианом и экватором, точка — отмеченное место; он стоит в шапке и в значке вкладки. «Клетка» и «Литера» остались запасными.
- Цикл сборки — недельный: прогон по понедельникам забирает выпуски радара за неделю. Тексты страницы «О методике», настройки кабинета и условные данные ленты, прогонов и версии «Что изменилось» переписаны под неделю.

## Что изменилось в v2

- Новые знаки атласа и словесная часть «Атлас AgPM»; лист с вариантами — `Атлас_логотипы_v2.html`. Значок вкладки — `assets/logo/favicon.svg`.
- Дизайн выправлен по методике unslop (Damir Sokolovsky, @heydamir, CC BY 4.0): одна нейтральная палитра «чернила» с тремя ролями текста, один акцент (кобальт), цвета только у сигналов; отступы с шагом 4 пикселя; один набор контурных значков вместо эмодзи и стрелок в тексте; подписи в предложениях без капса и разрядки; веса шрифта 400–600; три радиуса (8, 12, 16) и одна кривая анимации `--ease`. Убраны свечение фона, градиент в заголовке, подкрашенные подписи.
- На главной странице нет ссылок на архив и прежние версии: срез и число выпусков со ссылкой на AgPM Radar. Страницы «Версии» и «Кабинет» ушли из верхней навигации в подвал («Версии атласа», «Для редакторов») и на страницу «О методике».
- Контраст обеих тем проверен: текст и подписи не ниже 4,6:1 на всех поверхностях.

| `assets/img/radar.png` | значок AgPM Radar у ссылки на источник |

| `data/demo.js` | `window.ATLAS_DEMO` — условные данные для ленты, очереди, прогонов, настроек и одной версии «Что изменилось»; на сайте помечены «макет»; в рабочей версии не подключается |
| `tools/перенос_октябрьского_атласа.py` | скрипт переноса `atlasData` из октябрьского HTML в модель задания; образец для этапа 1 |

## Маршруты

В прототипе маршруты живут после `#`; в рабочей версии это настоящие пути из раздела «Сайт» задания.

| Прототип | Рабочая версия | Страница |
| --- | --- | --- |
| `#/` | `/` | главная матрица, паспорт открывается под ней |
| `#/scenario/<ключ>` | `/scenario/<ключ>/` | матрица с открытым паспортом; старые адреса `#<ключ>` переадресуются |
| `#/index?sec=&pr=&cor=&item=&mon=&ev=&ty=&q=&sort=` | `/index/?…` | указатель с фильтрами в адресе |
| `#/m/<номер>` | `/m/<номер>/` | указатель с раскрытой строкой материала |
| `#/sections`, `#/section/<ключ>`, `#/section/practice/<ключ>` | то же без `#` | разделы и практики |
| `#/versions`, `#/versions/<дата>` | то же | архив и «Что изменилось» |
| `#/method` | `/method/` | о методике |
| `#/editor/...` | `/editor/...` | кабинет: `feed`, `queue`, `material?num=`, `scenario?key=`, `sheet`, `refs`, `versions`, `runs`, `settings` |

## Что считается из данных

Счётчики коридоров, соседних территорий, легенды, подвала, разделов и месяцев; сигналы на матрице берутся из `items[].signal`, правило сигнала описано в задании. Выводы листа (`sheet_texts`) показываются по условиям: функция `conditions()` в `atlas.js` считает их по данным, подстановки `{claimed4}` и `{refuted4}` — словами. Пустые клетки находятся автоматически. Связь «учитывается для сигнала» (`links[].counts`) рассчитана скриптом переноса по правилу задания; исключение — обзор № 117 в сценарии «Подсказки и черновики планов».

## Темы

Переключатель в шапке меняет `data-theme` на `<html>` и запоминает выбор в `localStorage` (чтение и запись в обработке ошибок). По умолчанию тема берётся из настройки системы. Обе палитры собраны из одного нейтрального ряда «чернила»; знак атласа — SVG с `currentColor`, поэтому в обеих темах один файл.

## Чего в прототипе нет

Серверной части, настоящих правок (формы кабинета показывают состояние «Сохранено» без записи), сравнения двух версий, выгрузок, снимков `/v/<дата>/`. Кабинет открывается после любого ввода в форму входа — защиты нет. Строки и экраны с меткой «макет» построены на условных данных из `data/demo.js`.

## Что сделать в Claude Code первым

1. Перенести разметку и стили в шаблоны сборки сайта, заменив маршруты с `#` на пути; сохранить классы и переменные CSS.
2. Вынести расчёты из `atlas.js` (`conditions`, счётчики, правило сигнала) в серверный код сборки; в браузере оставить указатель, паспорт и переключатели.
3. Проверить, что версия 2026-10-09, собранная из базы, совпадает с этим прототипом по номерам, сигналам, счётчикам и текстам.
