## 2. Как проверено

`python -m atlas.cli first-version` собирает версию и сверяет её дважды:

1. **С базовыми данными** (`reference/…json`): номер, адрес, издание,
   название, суть, цифры, вывод, тип, доказательность, флаги, происхождение
   описания, раздел, практика, месяц и дата у каждого из 794 материалов;
   название, тексты, уровень и сигнал у каждого пункта; роль и оценка у каждой
   связи; правило сигнала; счётчики коридоров, территорий, разделов и легенды.
2. **С данными прототипа** (`prototype/atlas-site/data/atlas-2026-10-09.js`):
   полное совпадение всех полей, кроме добавленных из V2 (раздел 3). Одно
   расхождение правил: прототип оставляет «/» у адреса главной страницы сайта в
   `url_norm` (9 адресов вида `https://isopm.ru/`), задание велит его убирать.
   Это внутренний ключ склейки дублей, читатель его не видит.

Обе сверки входят в гейт `bash scripts/verify.sh` (35 проверок) и выполняются
на свежей тестовой базе при каждом прогоне.

## 4. Сайт

| Требование | Как сделано |
| --- | --- |
| Постоянные адреса | все страницы из таблицы задания — настоящие пути: `/`, `/scenario/<ключ>/`, `/index/`, `/m/<номер>/`, `/sections/`, `/section/<ключ>/`, `/section/practice/<ключ>/`, `/versions/`, `/versions/<дата>/`, `/method/`; всего 852 страницы |
| Старые адреса `/#ключ` | переадресуются на `/scenario/<ключ>/` |
| Снимки `/v/<дата>/` | та же папка версии работает под этим адресом, с плашкой «Версия на ДД.ММ.ГГГГ, актуальная — здесь»; закрыты от индексации |
| Числа на сайте | считаются при сборке из данных (`computed` снимка), не написаны текстом |
| Выводы листа | показываются по условиям, числа подставляются словами |
| Указатель | данные отдельным файлом, строки по 50; на 3000 синтетических строках фильтр срабатывает за 30–55 мс, поиск — 59 мс (порог 200 мс) |
| Вес главной | 182 КБ без шрифтов (порог 300 КБ) |
| Кэш | у скрипта, стилей и данных хэш содержимого в имени |
| Темы | светлая и тёмная, по умолчанию — как в системе, переключатель в шапке, без вспышки |
| Рубрикатор | левая колонка на указателе, разделах и паспортах, на узком экране — выезжающая панель |
| Заголовки и описания | у каждой страницы свой `<title>`, описание со счётчиками, canonical, Open Graph; `sitemap.xml`, `robots.txt` |
| Ширины | 390, 768, 1440 в обеих темах: без ошибок и без горизонтальной прокрутки (`tools/browser_check.cjs`, 84 отрисовки) |

Вид страниц взят из прототипа v3 без переделки: разметка, стили и логика
перенесены, маршруты переведены с `#/` на пути.

### Чего на сайте пока нет и когда появится

- **Кабинет редактора** и ссылка «Для редакторов» в подвале — этап 3, вместе со
  входом. Условные данные прототипа (`demo.js`) в сборку не входят.
- **Фильтр «только новые с прошлой версии»** и строка «с прошлой версии: …» на
  главной — появятся со второй версией, сейчас сравнивать не с чем.
- **Картинка для соцсетей** (снимок матрицы) и печать на A3 — этап 3, вместе с
  публикацией.
- **Проверка доступности axe-core и сравнение снимков с эталонными** — этап 3,
  в предохранителях публикации.

```

.venv/bin/python -m atlas.cli import --radar-dump var/radar-dump --unmatched var/unmatched-2026-10-09.json
.venv/bin/python -m atlas.cli first-version
.venv/bin/python -m atlas.cli build-site
bash scripts/verify.sh
```
