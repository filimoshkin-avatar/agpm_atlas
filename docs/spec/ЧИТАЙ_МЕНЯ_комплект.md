# Комплект для Claude Code: Атлас агентного управления проектами, v1

Всё, что нужно для разработки приложения «Атлас AgPM» по заданию v2: само задание, фронтенд-прототип v3, исходный октябрьский атлас, его данные в модели задания и знаки атласа. Атлас собирается раз в неделю из материалов AgPM Radar (radar.agpm.space).

С чего начать: прочитать `Задание_на_разработку_Атлас_v2.md` целиком, затем `atlas-site/ЧИТАЙ_МЕНЯ.md`, затем выполнить раздел задания «Первые шаги Claude Code» и остановиться после записки разведки.

## Что считать истиной при расхождениях

Правила атласа, модель данных и критерии приёмки — в задании. Вид страниц — в прототипе. Числа, сигналы и тексты эталона — в базовых данных октябрьского атласа; прототип показывает их в модели задания, и версия 2026-10-09, собранная из базы, должна совпасть с прототипом по номерам, сигналам, счётчикам и текстам.

Оформление и знак — отдельного продукта «Атлас AgPM». Логотипов и ссылок других продуктов на сайте нет; единственная внешняя ссылка — на AgPM Radar. Знак берёт цвет текста через `currentColor`, точка — акцент темы через `--logo-dot`.

## Открытые вопросы заказчику

Перечислены в последнем разделе задания; до записки разведки нужны адрес и ключ выгрузки радара, доступ к языковой модели радара, адрес сайта, редакторы и каналы оповещений, подтверждение дня и времени прогона (принято: понедельник, 09:00 МСК).
