# Отчёт этапа 2, v1

1 ноября 2026 · этап 2 задания «Еженедельный Атлас агентного управления проектами», v2

Конвейер написан и прошёл догрузку трёх недель после атласа 9 октября. В атлас
вошли 137 новых материалов, номера с № 798 по № 934. Получились три версии,
2026-10-13, 2026-10-20 и 2026-10-27. Все три в состоянии «ждёт проверки», на
сайт ничего не выкладывалось. Для приёмки этапа нужна ваша проверка: выборка
из 50 новых материалов и обе смены сигнала (раздел 4).

Оценки классификатора на эталоне не было — по решению заказчика 01.11.2026
(записка разведки, раздел 9).

## 1. Что сделано

| Шаг недельного цикла | Как сделано |
| --- | --- |
| Забор | переходник к API V2 с таблицей соответствия полей (`atlas/radar_fields.json`); курсор прошлого прогона с нахлёстом 3 дня; склейка по нормализованному адресу; повторный прогон не создаёт дублей |
| Сверка | текст статьи берётся сначала из кэша радара, иначе страница открывается сама (AgPM-Atlas/1.0, robots.txt, раз в секунду на сайт); модель сравнивает описание радара с текстом и даёт вердикт: подтверждено, исправлено, не про эту страницу |
| Классификация | сверка и классификация — одним запросом на материал (`prompts/material_v2.md`); правила вставляются в запрос прямо из `Правила_атласа.md`, примеры — шесть ближайших материалов ручной разметки; ответ проверяется по закрытым спискам |
| Проверки кода | **цифры:** каждое число сути должно быть в тексте источника или в карточке радара, иначе материал переносится на следующий прогон; **цитаты:** связь учитывается для сигнала, только если её цитата дословно есть в тексте источника; **язык:** «ёлочки», неразрывные пробелы, запрещённые слова (одна перегенерация, потом очередь редактора) |
| Пересчёт | сигналы по правилу; смены записываются в историю сигнала и в очередь редактора; новые номера с № 798 |
| Версия | снимок со страницей «Что изменилось» в состоянии «ждёт проверки»; предохранитель «резкие изменения» посчитан |
| Модель | `openai/gpt-6.1-sol` через `openclaw infer` в профиле радара; каждый ответ кэшируется, поэтому прерванный прогон продолжается без повторных обращений |

По ходу пришлось поправить три вещи: инструкцию до версии 2 (цифры короткими
записями, вывод только при конкретном действии), проверку цифр (английские
числительные: «six» — это 6) и разбор флагов (модель писала «как заявлено» без
кавычек). Гейт — 57 проверок, включая сквозной прогон недели на записанной
выгрузке с заглушкой модели.

## 3. Смены сигналов

Сменились два сигнала, оба в версии 2026-10-20, у обоих было «Заявлено», стало «Подтвердилось»:

- «Сбор статусов и поиск пропусков»;
- «Поиск рисков и отклонений».

**Обе смены держатся на одном материале — № 836**: «ЕДИНЫЙ ЦУПИС и Shtab
получили премию CNews за внедрение ИИ-агентов в управление проектами»,
vedomosti.ru. Модель сочла его рассказом самой организации-пользователя
(роль «внедрение с именем»), и цитата действительно есть в тексте источника:
«Система автоматически формирует сводки по задачам… помогает выявлять
потенциальные риски и узкие места».

**Сомнение, которое надо разрешить редактору.** По заголовку это новость о
премии и может быть пресс-релизом продавца Shtab. Тогда верная роль — «кейс по
данным продавца», связь не учитывается, и оба сигнала остаются «Заявлено». Это
первый пункт проверки.

Ещё две учитываемые связи сигналов не меняют: сценарии и так «Подтвердилось».

- № 862, FirstRand на news.sap.com → «Код по задачам из списка»;
- № 909, НЛМК ИТ на habr.com → «Интеграции и миграции систем».

Предохранитель «резкие изменения» не сработал ни в одной неделе: смен сигнала
не больше трёх, старые связи не менялись.

## 4. Что проверить редактору

Страница проверки — `tools/review_page.py`, файл передан отдельно. На ней все
137 материалов по неделям, выборка из 50 отмечена рамкой (переключатель
«только выборка»). Сверху — смены сигналов с цитатами.

1. **№ 836 и обе смены сигнала** (раздел 3).
2. **Выборка из 50 материалов:** раздел, практика, тип, доказательность, связи и суть.
3. **Четыре исключённых материала.** Самый спорный — «PMI Releases New Standard for Artificial Intelligence in Project Management»: модель исключила его как материал не об агентах, а он мог бы лечь в «Нормы и стандарты».
4. **Два кандидата в новые сценарии:** «Самостоятельный цикл исследовательских экспериментов», «Автономное восстановление кода с машинной приёмкой». Автоматически в сценарии они не превращаются.
5. **Описание не про страницу:** одна карточка радара о проектном офисе ведёт на заметку Moneycontrol об инвестиционных агентах.

**Сейчас перенесены два материала.** Они разберутся сами в ближайшем
прогоне:

- в одном модель привела число «61», которого нет в тексте источника, — проверка сработала правильно;
- Procore отвергнут из-за написания флага, это уже исправлено.

В таблице раздела 2 перенос считается по прогонам: материал, перенесённый
дважды, учтён в обеих неделях.

## 5. Чего ещё нет

- **Публикации.** Версии не выложены. Выкладка на сайт, атомарное переключение, откат, расписание, оповещения и кабинет — этап 3. Ему нужен ответ на вопрос 3 записки (где работает кабинет) и разрешения на DNS, Caddy и расписание.
- **Неделя 28.10–02.11.** Её заберёт первый плановый прогон (понедельник, 02.11) или внеочередной запуск.
- **Пересказа текстов паспорта** («почему» и опорный факт) после смены сигнала. Сейчас смена сигнала ставит задачу редактору, автоматическое переписывание текстов не сделано.
- **Безголового браузера для страниц, которые без него не открываются.** Пока такие материалы остаются с описанием радара. Сейчас это 2 из 143.
- **Ёфикации.** Нужен словарь однозначных слов от заказчика.
- **Склейки кандидатов в сценарии по смыслу.** Кандидаты копятся в очереди редактора.
